# Disconnect Parley

Removing or disabling the host connection stops that host from making future local requests; it does
not revoke the Parley connection in the portal. Revoking the connection in the Parley portal invalidates
that connection's access server-side.

Choose the action that matches the request. For a complete removal, revoke in the portal and then remove
or disable the host connection. Do not report a credential as revoked merely because a local host entry
was removed.
